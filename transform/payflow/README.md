# PayFlow dbt project

Medallion transforms for PayFlow, run with dbt + DuckDB. DuckDB reads Bronze Parquet straight from Cloudflare R2 (`httpfs`) and writes Silver and Gold back to R2; there is no warehouse cluster.

| Layer | Path | Materialization | Notes |
| --- | --- | --- | --- |
| Staging | `models/staging/` | view | Reads Bronze from R2. Deduplicates to one row per key so downstream joins stay one-to-one. |
| Silver | `models/silver/` | incremental / table | Typed, FX-normalized, PII hashed (`silver_accounts`). `silver_transactions` and `silver_telemetry_events` are incremental (`delete+insert`). |
| Gold | `models/gold/` | table | ML features and aggregates, rebuilt on every run. |
| Marts | `models/marts/` | table | Star schema (`fct_transactions`, `dim_merchants`, `dim_date`) and BI marts. |
| Seeds | `seeds/mcc_catalog.csv` | seed | 981 MCC codes with `mcc_category` and `risk_tier` (generated by `scripts/generate_mcc_catalog.py`). |

Tests: generic `not_null`, `unique` and `relationships` tests in the `schema.yml` files, plus singular tests in `tests/` (`assert_fraud_rate_valid`, `assert_amount_usd_coverage`).

## Running

```bash
export R2_ENDPOINT=... R2_ACCESS_KEY_ID=... R2_SECRET_ACCESS_KEY=...   # see ../../.env.example
dbt seed --profiles-dir .
dbt run  --profiles-dir .
dbt test --profiles-dir .
```

`dbt parse --profiles-dir .` validates SQL and YAML without touching R2; CI runs it on every push, and runs seed + run + test on `main`.
